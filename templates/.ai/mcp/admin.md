# MCP — Admin

## Назначение
Даёт агенту безопасные доменные операции через существующий admin API, а не прямую запись в базу.

## Когда использовать
Когда нужно изменить бизнес-данные и при этом сохранить валидацию, события, аудит, кэш и поиск.

## Границы
Не дублировать в MCP бизнес-логику. Он должен вызывать уже существующие защищённые операции приложения.
