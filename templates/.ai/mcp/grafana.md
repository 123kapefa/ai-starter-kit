# MCP — Grafana и логи

## Назначение
Даёт доступ к логам, метрикам и трассировкам для диагностики поведения системы.

## Когда использовать
При инцидентах, деградации производительности и ошибках, которые не воспроизводятся локально.

## Границы
Учётные данные живут в окружении, не в Git. Production-доступ включается отдельно и должен быть read-only.
