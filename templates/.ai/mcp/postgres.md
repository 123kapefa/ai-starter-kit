# MCP — PostgreSQL

## Назначение
Позволяет диагностировать данные и схему базы для конкретного сервиса.

## Когда использовать
При расследовании ошибки данных, миграции или несоответствия между API и хранилищем.

## Границы
По умолчанию read-only и local/dev. Для нескольких сервисов — отдельное подключение на каждую базу, а не один общий доступ.
