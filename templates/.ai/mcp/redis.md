# MCP — Redis

## Назначение
Помогает диагностировать кэш, очереди и производное состояние.

## Когда использовать
Когда данные в API, БД и интерфейсе расходятся из-за кэширования или фоновой обработки.

## Границы
Не изменять production-ключи напрямую без отдельного процесса и подтверждения.
