# Router

## Когда использовать
В начале неясной задачи, когда ещё непонятно: уточнять требования, исследовать, писать спецификацию, чинить баг или сразу реализовывать.

## Главный принцип
Router только рекомендует маршрут и объясняет выбор. Он не начинает работу сам — следующий шаг выбирает человек.

## Маршруты
- неясна цель → `clarify`
- решение уже принято, нужна фиксация → `spec`
- большую работу нужно разложить → `decompose`
- известна ошибка → `fix-bug`
- запутан домен (термины, сущности, правила) → `domain-modeling`
- план согласован → `implement`

## Связано
`clarify` · `spec` · `decompose` · `fix-bug` · `implement`
