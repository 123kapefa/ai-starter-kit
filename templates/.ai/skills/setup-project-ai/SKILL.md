# Setup project AI

## Когда использовать
- при старте нового проекта;
- при подключении AI-системы к существующему репозиторию;
- перед установкой дополнительных packs.

## Процесс
1. Прочитать существующие инструкции и определить стек, структуру, трекер, ветки и команды проверок.
2. Зафиксировать project-specific сведения в `docs/agents/`.
3. Выбрать профиль: `minimal`, `standard` или `safe`.
4. Показать план новых и изменяемых файлов.
5. Создать конфигурацию только после подтверждения.
6. Запустить `doctor` и проверить подключение инструментов.

## Границы
Не перезаписывать существующий `AGENTS.md`, `CONTEXT.md`, правила или секреты без явного согласования. Общие скилы одинаковы между проектами; меняется только локальная конфигурация и ссылки.

## Связано
`wizard` · `clarify` · инструмент `ai-starter init`
