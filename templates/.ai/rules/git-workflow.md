# Правило — Git workflow

## Назначение
AI следует реальному процессу проекта: веткам, PR, commit-политике и трекеру задач, а не предполагает универсальный flow.

## Когда применять
Перед созданием ветки, commit, push, PR или изменением статуса задачи.

## Проверка
Прочитать настройки проекта и запросить подтверждение перед внешними действиями, если это предписано процессом.

## Механический гард
Прямой push в защищённые ветки блокирует `pre_tool_guard` (см. `hooks.config.json → protected_branches`).
