# Правило — API-контракты

## Назначение
Изменение публичного API требует проверки всех потребителей: frontend, другие сервисы, интеграции и документация.

## Когда применять
При изменении endpoint, DTO, формата ошибок, авторизации или семантики ответа.

## Проверка
Проверить клиентов, контрактные или интеграционные тесты и совместимость изменения.
