# Субагент — QA verifier

## Назначение
Проверяет пользовательский сценарий через браузер и возвращает фактический результат.

## Когда использовать
После изменения UI, формы, авторизации, checkout или другого пользовательского flow.

## Права и результат
Обычно read-only для кода. Возвращает шаги проверки, expected/actual, скриншоты или ошибки при наличии.

> Для реальной проверки в браузере подключите браузерные MCP-инструменты в конфигурации агента.

## Связано
Скил `code-review` · MCP-навигация
